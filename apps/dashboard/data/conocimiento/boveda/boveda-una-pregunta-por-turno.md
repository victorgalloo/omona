- La gente contesta una pregunta. Ante cuatro, contesta la más fácil o ninguna.
- Cada respuesta decide cuál es la siguiente pregunta.
- La conversación se siente como plática, no como formulario.
- Cómo se hace
  - Antes de escribir el agente, anoto qué necesito saber para pasar el prospecto a un vendedor.
  - Ordeno esos datos del más fácil de contestar al más delicado.
  - El agente pregunta el primero que falta. Solo ese.
  - Hasta el fondo
    - Si la persona ya dio un dato sin que se lo pidieran, no se le vuelve a preguntar.
    - Si pregunta algo ella, primero se le contesta y después sigue la calificación.
    - Cuando ya está lo mínimo, se deja de preguntar y se hace el traspaso. Ver [El traspaso lleva resumen](#boveda-el-traspaso-lleva-resumen).
- Por qué
  - Un mensaje largo en WhatsApp se lee a medias.
  - Una pregunta corta se contesta desde el celular, caminando.
